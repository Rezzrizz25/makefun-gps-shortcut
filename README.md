## The entry

One line, 145 characters, in the GPS's own voice: smug, defensive, and blaming the map — as entered in [The GPS Swears It Was a Shortcut](https://make.fun/bounty/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9) on make.fun.
